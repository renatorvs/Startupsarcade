## 📖 Descrição do Projeto

**StartupsArcade** é uma plataforma revolucionária que cria uma comunidade vibrante para startups. Diferente de outras plataformas, StartupsArcade combina:

- 🎮 **Gamificação** - Engajamento através de pontos e desafios
- 🏢 **Rede Empresarial** - Conectar fundadores e investidores
- 📊 **Business Model** - Ferramentas para planejar e validar ideias
- 🎯 **Categorização** - Organizar startups por segmento

### 💡 Canvas de Modelo de Negócio

Uma ferramenta integrada para criar e compartilhar o **Business Model Canvas**:

#### 9 Blocos do Canvas:
1. **Segmentos de Clientes** - Quem você atende?
2. **Proposição de Valor** - Qual problema resolve?
3. **Canais** - Como chega até o cliente?
4. **Relacionamento com Clientes** - Como mantém contato?
5. **Fluxo de Receita** - Como ganha dinheiro?
6. **Recursos Principais** - O que é essencial?
7. **Atividades-Chave** - O que faz funcionar?
8. **Parcerias Principais** - Quem precisa? (investors, partners)
9. **Estrutura de Custos** - Quanto custa?

#### Funcionalidades:

## 🚀 Como Usar

### Requisitos
- PHP 7.0+
- MySQL 5.7+
- Composer
- Apache com mod_rewrite

### Instalação

1. **Clone o repositório**
```bash
git clone https://github.com/renatorvs/Startupsarcade.git
cd Startupsarcade
```

2. **Instale dependências**
```bash
composer install
```

3. **Configure o banco**
```bash
cp config/database.example.php config/database.php
# Edite com suas credenciais
```

4. **Execute migrações**
```bash
mysql -u usuario -p banco < database/migrations.sql
```

5. **Inicie o servidor**
```bash
php -S localhost:8000
```

6. **Acesse**
```
http://localhost:8000
```
